🏦 Bankist App

A simple banking application built with HTML, CSS, and JavaScript as part of my JavaScript learning journey.

✨ Features

User Login: Log in using a username and PIN.

Account Balance: View the current account balance.

Transaction History: Display deposits and withdrawals.

Account Summary: Calculate total deposits, withdrawals, and interest.

Money Transfers: Transfer money between accounts.

Request a Loan: Request a loan when the account meets the eligibility condition.

Close Account: Close an account using the correct username and PIN.

Sort Transactions: Sort movements by amount.

Dynamic UI: Update the interface based on account activity.

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6+)

DOM Manipulation

Array Methods (map, filter, reduce, find, findIndex, some, every, flatMap, and toSorted)

JavaScript Objects and Arrays

Event Handling

Map and Object.groupBy()
